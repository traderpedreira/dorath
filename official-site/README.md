# Dorath — site oficial (prévia)

Primeira estrutura do site público do Dorath.

## Páginas
- `index.html` — apresentação e chamada para playtest
- `o-jogo.html` — conceito e arquitetura do jogo
- `playtest.html` — recrutamento de testadores
- `diario.html` — diário de desenvolvimento

## Estado
O formulário de playtest ainda é demonstrativo. Antes da publicação pública, conectar a persistência, política de privacidade, analytics e domínio próprio.

## Deploy
A pasta foi criada separadamente do app para permitir publicação independente no Cloudflare Pages.
